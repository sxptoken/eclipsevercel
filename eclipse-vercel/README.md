# ECLIPSE Vercel Site

Purple ECLIPSE dashboard for a GitHub → Vercel deployment.

## Deploy
1. Create a GitHub repository.
2. Upload these files.
3. In Vercel, import the GitHub repository.
4. Deploy.

Vercel functions are stateless, so the example donation count is a demo value. Use a persistent database for a real shared donation counter.

The site intentionally does not include live authentication-token refresh or credential distribution.
